PROG 02 API examples

Small, runnable examples of calling a language model on the ballot measure data pack. Each page shows the exact prompt it sends and the full reply it gets back. Class examples, not official voter information.

  1. Summarize a ballot measure
    Pick a measure and a length; the model summarizes the legal text.
  2. Reading level (Flesch–Kincaid)
    Compute the grade level of a measure's legal text. No AI.
  3. How much have I spent?
    Ask OpenRouter how much your API key has used and how much is left. Free.
  4. Rewrite at a reading level
    The model rewrites a measure for a chosen grade; Flesch–Kincaid checks the result.
  5. One topic of concern: Prop 4 and My Taxes
    The model reads Prop 4 and explains what it means for your taxes: what the text says, then its own opinion.
  6. Generate an image
    Send a text prompt to an image model and show the picture. About $0.04 per image.
