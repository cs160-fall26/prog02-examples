3. How much have I spent?

Asks OpenRouter how much your API key has spent so far. This call is free and uses no AI. It sends a GET request to a different address: https://openrouter.ai/api/v1/key

You can also run it from the command line (Terminal). Replace YOUR_KEY with your key:

curl https://openrouter.ai/api/v1/key -H "Authorization: Bearer YOUR_KEY"
